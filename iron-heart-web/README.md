# Ironheart — React + Tailwind web app

## Requirements
- Node.js 18+ recommended

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Notes
- This is a responsive web dashboard with a CSS double-beat animation and glow.
- The camera area is a simulated preview, not a real camera feed or real person detector.
- The BPM button toggles a demo heart rate between 72 and 96.
- `public/heart.png` is the glossy heart artwork used by the animation.
